# Repository map

- `src/illustrator_agent/`: reusable design components and public authoring API.
- `examples/`: complete Python-authored Illustrator documents.
- `docs/design-model.md`: render contract and design-semantics policy.
- `docs/architecture.md`: Layer 2/3 responsibilities and Layer 1 boundary.
- `../py-ai-illustrator/`: sibling Layer 1 repository for `.ai` IR, parsing, writing, patching, validation, and preview.

Run repository commands from the `illustrator-agent` root. The local development dependency expects both repositories under the same parent directory.
